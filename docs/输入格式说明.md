# AI 迷宫玩家 — 输入格式说明

## JSON 格式

```json
{
  "maze": [["#", "S", "#"], [" ", "G", "E"]],
  "B": [11, 13, 9, 15],
  "PlayerSkills": [[8, 4], [2, 0], [4, 2], [6, 3]],
  "minRouds": 20,
  "CoinConsumption": 5
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `maze` | `string[][]` | 迷宫二维数组 |
| `B` | `number[]` | Boss 血量数组，共 n 个 Boss，击败顺序固定 |
| `PlayerSkills` | `[number, number][]` | 玩家技能，`[伤害, 冷却回合]` |
| `minRouds` | `number` | 本轮击败 Boss 所需最少回合数 |
| `CoinConsumption` | `number` | 超回合后每回合金币消耗，已击败的 Boss 血量可见 |

## 迷宫字符含义

| 字符 | 含义 | 说明 |
|------|------|------|
| `S` | 起点 | AI 初始位置 |
| `E` | 终点 | 目标位置 |
| `B` | Boss | 守卫终点的 Boss，击败后方可通过 |
| `#` | 墙壁 | 不可通行 |
| ` ` (空格) | 普通通路 | 可通行 |
| `G` | 金币 | 收集 +50 金币 |
| `T` | 陷阱 | 经过 -30 金币 |

> **移动规则**：除 `#` 外所有字符均视为可通行。两个可通行格子上下左右相邻则存在一条边（四方向移动，不支持斜对角）。
